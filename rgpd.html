    Confidentialité · RGPD

    Vos données personnelles.

    Ce que ce portfolio utilise, pourquoi, et comment garder la main sur vos données.

    Dernière mise à jour : 15 octobre 2026

    1. Qui s’occupe de vos données ?

    Le portfolio est édité par Youen Le Buan, responsable des traitements liés à ses échanges. Pour une question ou une demande concernant vos données : youenlebuan@gmail.com.

    2. Ce qui est utilisé

    Le site ne propose ni compte utilisateur, ni formulaire, ni paiement. Aucun outil de mesure d’audience n’est intégré au code du portfolio.

    • Vos messages : si vous écrivez par e-mail, votre adresse, le contenu du message et les informations que vous décidez d’y joindre sont reçus dans la messagerie Gmail de Youen. Ils servent à répondre à votre demande et à suivre l’échange. Le traitement repose sur les démarches précontractuelles lorsque votre demande concerne une collaboration, ou sur l’intérêt légitime à répondre aux autres demandes.
    • Les données techniques : l’hébergement et les fournisseurs de ressources reçoivent les informations nécessaires à une connexion, notamment l’adresse IP et les informations techniques du navigateur, pour délivrer et sécuriser les pages.

    Les messages sont conservés le temps nécessaire à leur traitement et au suivi de l’échange. Si une conservation est nécessaire pour une obligation légale ou la défense d’un droit, seuls les éléments utiles sont conservés pendant la durée correspondante.

    3. Vidéos YouTube

    Les vidéos des projets sont intégrées directement depuis YouTube, sans lecture automatique, avec le domaine youtube-nocookie.com. Le portfolio n’enregistre aucun choix de préférences dans votre navigateur.

    Le lecteur est fourni par YouTube, service de Google. Pour connaître les traitements de données liés à ce service, consultez la politique de confidentialité de Google.

    4. Hébergement et autres prestataires

    L’hébergement actuel repose sur GitHub Pages. GitHub indique enregistrer l’adresse IP des visiteurs à des fins de sécurité, même sans connexion à un compte GitHub. Les durées dépendent des finalités et obligations du prestataire ; elles ne sont pas fixées par Youen. Voir la documentation GitHub Pages et la politique de confidentialité de GitHub.

    Les polices sont chargées depuis Google Fonts ; les bibliothèques d’animation depuis cdnjs et jsDelivr. Ces connexions ont lieu à l’ouverture des pages. Les destinataires techniques sont les fournisseurs de ces services. Leurs traitements sont décrits dans les politiques de Google, Cloudflare, qui distribue cdnjs, et jsDelivr.

    Ces services et la messagerie peuvent traiter des données hors de l’Espace économique européen. Leurs politiques présentent les lieux de traitement, les durées et les garanties de transfert qu’ils appliquent. Les liens vers les réseaux sociaux ne les chargent pas dans le portfolio ; les ouvrir vous conduit vers leurs propres services.

    5. Vos droits

    Selon le traitement et les conditions prévues par le RGPD, vous pouvez demander l’accès, la rectification, l’effacement ou la limitation de vos données, vous opposer à certains traitements et demander la portabilité. Vous pouvez retirer un consentement à tout moment, sans remettre en cause les traitements antérieurs.

    Pour les données traitées par Youen, écrivez à youenlebuan@gmail.com. Une réponse est apportée dans le délai prévu par le RGPD, en principe un mois. Pour les données gérées directement par les prestataires, leurs politiques indiquent leurs contacts.

    Vous pouvez vous informer sur vos droits auprès de la CNIL et, si nécessaire, lui adresser une réclamation.
